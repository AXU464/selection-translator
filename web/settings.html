      FORMULAS
公式写法修改

      
把鼠标放在可修改的变量公式上，会看到轻微高亮和「右键修改公式」提示。右键打开写法列表，点选即可替换这一处。其他位置的相同公式各自独立。

      
列表展示实际排版，当前写法打勾。括号、集合、分式、根号和环境中的变量也可独立调整。变量的函数上标会保持为整体参与重排。求和、积分等算符自身的上下限，以及分式、根号和环境的结构参数保留原样。

      
自己输入 LaTeX
列表最后一项可输入裸公式，例如 g^{m_i}。不要添加 $、$$、\[…\] 或 \(…\)。输入后即时预览，语法错误会显示在输入框旁。应用后跟随原来的行内或行间形态。

      
修改立即更新历史。复制和导出使用当前显示写法。选错了可以再次右键选择，不提供撤销。

      
键盘操作说明
按 Tab 聚焦高亮公式，按 Enter 或 Shift+F10 打开列表。方向键切换候选，Home 和 End 到首尾，Enter 确认，Esc 关闭。手写输入框中的 Enter 保持换行。

      
写法学习
新翻译默认显示 API 返回的公式，历史评分只调整右键候选的排列顺序。关闭卡片或切换翻译时，每处最终显示的写法记一次保留，被改掉的写法扣分。相同内容权重更高，分数按 30 天半衰期衰减。已修改并保存的历史保持上次写法。

      

      
本地存储占用
自动数据总预算为 1GB。超限按日志、缓存、最旧历史、最久未用学习偏好的顺序清理。导出文件单独统计，请自行清理。
