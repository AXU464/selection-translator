# 划词翻译（Selection Translator）

常驻托盘的 Windows 划词翻译小工具：**在任意程序里用鼠标选中一段文字**，选区旁边会弹出
`Translate into Chinese` / `Translate into English` 两个按钮；点击后调用 **DeepSeek
（deepseek-flash）** 完成翻译，并把结果渲染成带 **Markdown + LaTeX 公式**的漂亮页面。

适用于看论文、看文档、看网页时随手翻译公式和排版内容。已有 LaTeX 公式要求保持原样；
从 PDF 复制的非 LaTeX 公式会结合上下文尽力重构为可显示的公式。Markdown
结构（标题、列表、表格、代码块）保持原样。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 划词弹窗 | 鼠标划选文字（拖拽 ≥5px 或双击选词）后，在鼠标位置弹出两个翻译按钮 |
| 不抢焦点 | 弹窗使用 `WS_EX_NOACTIVATE`，弹出后会立刻把焦点还给原来的窗口，阅读/输入不被打断 |
| 完全静默 | 弹窗与结果窗口都不进任务栏、不进 Alt+Tab（清掉了 WinForms 自动加的 `WS_EX_APPWINDOW`）；想让结果窗口出现在任务栏，把 `ui.result_in_taskbar` 设为 `true` |
| 双语方向 | 译成中文（简体）/ 译成英文，在结果卡片的「更多 → 反向翻译」切换方向 |
| 本地语言筛查 | 中文 → 中文、英文 → 英文直接显示「选中语言类型与目标一致」，不调用 DeepSeek；中英文混合一律按英文处理，只允许译成中文 |
| 公式与排版 | 结果页用 KaTeX 渲染 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`、`\begin{...}` 等公式，marked 渲染 Markdown；代码块、表格、引用、货币符号 `$5` 都正确区分 |
| PDF 公式重构 | 修复连字与软连字符；结合上下文恢复复制后散乱的上下标、分式、求和/求积、算子限定符，优先显示重构公式；长公式可以横向滚动 |
| 原文核对 | PDF 译文下方可进入原始文本，保留复制时的换行与字符，并可切换排版预览；复制原文仍得到未经修复的选区内容 |
| 流式输出 | 边翻译边显示（约 0.6–1s 出首字），翻译完再整体渲染公式 |
| 剪贴板保护 | 为了拿到选中文字会临时按一次 Ctrl+C，之后**自动把原剪贴板内容还原** |
| 快捷键 | `Ctrl+Alt+C` 译成中文、`Ctrl+Alt+E` 译成英文（对当前选中文字生效，可选关闭） |
| 托盘菜单 | 暂停/启用划词、翻译剪贴板、显示结果窗口、打开配置/日志、开机自启、退出 |
| 结果卡片 | 无边框阅读卡片，默认占工作区的 **1/4 宽 × 1/4 高**（1920×1080 → 480×258）；顶部拖动区显示四向十字光标，四边/四角均可拉伸，也可用「− / ＋」缩小、放大；窗口大小与位置会被记住 |
| 专注阅读 | 顶部仅保留复制、缩放、更多与关闭；原文、历史、重试、设置、日志与翻译信息收进「更多」，配套浅色/深色主题；长译文在卡片内滚动查看 |
| 可视化设置 | 独立设置窗口包含外观、翻译服务、划词与快捷键；保存后立即应用，无需打开配置文件或重启 |
| 主题风格 | 参考 time_budget 的 14 套配色，另有跟随系统模式；设置、译文卡片、划词按钮统一换肤，支持即时预览与取消恢复 |
| 单实例 | 重复启动会提示已在运行，避免重复挂钩子 |

## 安装与启动

需要 **Python 3.10+**（已在 3.11.9 上实测）与 Microsoft Edge WebView2 运行时
（Windows 10/11 通常已自带；缺失时打开 [WebView2 下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装）。

```bat
cd <本项目所在目录>
python -m pip install -r requirements.txt
```

启动方式（任选其一）：

- 双击 `run.vbs` —— **无控制台窗口**，日常使用推荐；
- 双击 `run.bat` 或 `python main.py` —— 带控制台，方便看日志排错。

首次启动会在托盘中出现「**译**」图标，并弹出一次使用说明窗口。

> 如果托盘里看不到图标，点一下任务栏的「^」展开隐藏图标区域。

## 使用

1. 在任意程序里用鼠标划选文字 → 选区旁弹出两个按钮 → 点击需要的目标语言。
2. 或者用快捷键：选中文字后按 `Ctrl+Alt+C`（中文）/ `Ctrl+Alt+E`（英文），跳过弹窗直达结果。
3. 结果卡片：顶部复制图标复制译文 Markdown；`− / ＋` 每次缩小/放大约 20%；
   在顶部图标、文字或点状把手处按住拖动即可移动，拉扯任意边缘或角落即可调整尺寸（最小 300×160）。
   `··· 更多` 中可查看原文、反向翻译、重试、恢复默认大小、回看历史、打开设置或日志。
   查看原文时点击「返回译文」或按 `Esc` 回到原来的阅读位置；菜单支持 `Esc` 关闭、`Tab` 切换。
4. 关闭结果窗口只是隐藏，程序仍在托盘运行；若原窗口中仍保留同一段选中文字，
   选区旁会重新出现翻译按钮，无需重新划选。切换到其他窗口、取消或更改选区、暂停划词后不会恢复旧按钮。
   从托盘菜单「退出」才会真正结束。

翻译前按选区字符在本地筛查：只要包含英文字母（含全角），不论中英文占比都按英文处理；
只有汉字的文本按中文处理（包含繁体），数字、标点和空白不影响判断。
纯数字/符号等无法判断语言的内容保留原有翻译行为。此规则用于中英文，不是通用多语种识别。
筛查覆盖划词、快捷键、剪贴板、重试和反向翻译。同语言提示不会计入翻译历史，
可以从「更多 → 反向翻译」改用另一种目标语言。

### 托盘菜单

- **划词翻译** —— 勾选 = 启用划词检测，取消 = 暂停（快捷键同时失效）
- **翻译剪贴板 → 中文 / English** —— 直接翻译剪贴板里的文本
- **显示结果窗口** / **设置与主题** / **打开日志目录**
- **开机自启** —— 首次运行默认开启，在「启动」文件夹创建快捷方式；取消后会记住选择，不会在下次启动时重新开启。取消时快捷方式进入回收站。
- **退出**

## 设置与主题

从译文卡片的「更多 → 设置」，或托盘的「设置与主题」打开配置窗口。

- **外观与阅读**：跟随系统，以及雾白、暖砂、冰川、青瓷、樱花、藤萝、奶油、银灰、钴蓝、赤陶、碧湾、石墨、莓酒、荧光 14 套主题；还可调整字号、置顶、自动收拢和任务栏显示。
- **翻译服务**：API Key、模型、流式输出、深度思考、额外翻译要求；高级区域提供 API 地址、温度、输出上限、超时和重试。
- **划词与快捷键**：划词检测、双击、剪贴板恢复、按钮收起时间、字符上限，以及中英文快捷键。

主题与字号可即时预览。点击「保存设置」持久保存并应用；点击「取消」、按 Esc 或关闭设置窗口
会撤销未保存的预览。已经保存的内容会保留。密钥不会回填到页面，留空保存不会覆盖原密钥；
快捷键冲突或输入不合法时会提示修正，保存失败不会部分写入配置。

底层仍使用首次运行自动生成的 `config.json`，需要调整未显示在窗口中的高级选项时可以手动编辑，
再重启应用。示例：

```jsonc
{
  "api": {
    "base_url": "https://api.deepseek.com",
    "api_key": "sk-...",              // DeepSeek API Key
    "model": "deepseek-flash",        // DeepSeek-V4.1-Flash
    "temperature": 0.2,
    "max_tokens": 16000,
    "thinking": false,                // false = 关闭思考链，翻译更快（约 0.6s 首字）
    "stream": true,                   // 流式输出
    "timeout_seconds": 120,
    "retries": 1,                     // 网络类错误自动重试次数
    "extra_instructions": ""          // 追加给模型的额外要求（如术语表）
  },
  "behavior": {
    "detect_selection": true,         // 划词总开关
    "double_click_select": true,      // 双击选词也弹按钮
    "drag_threshold_px": 5,           // 拖拽多少像素算“划选”
    "min_chars": 2,                   // 少于这么多字符不弹窗
    "max_chars": 12000,               // 超长选区截断上限
    "capture_delay_ms": 70,           // 取词前的等待，给源程序一点时间完成选中
    "restore_clipboard": true,        // 取词后还原原剪贴板内容
    "auto_dismiss_seconds": 9,        // 弹窗自动消失秒数（0 = 不自动消失）
    "hotkey_chinese": "ctrl+alt+c",
    "hotkey_english": "ctrl+alt+e",
    "hotkey_enabled": true
  },
  "ui": {
    "theme": "system",               // system 或 themes.json 中的主题 ID
    "font_size": 14,                  // 结果窗口正文字号
    "popup_offset": [12, 18],         // 弹窗相对鼠标的偏移（像素，逻辑坐标）
    "result_on_top": false,           // 结果窗口是否置顶
    "fit_to_content": false,          // false = 保持卡片尺寸，滚动查看；true = 短译文时自动收缩高度（本次运行手动缩放后停止自动收缩）
    "result_in_taskbar": false,       // 结果窗口是否占用任务栏/Alt+Tab（false = 完全静默，从托盘「显示结果窗口」打开）
    "debug_webview": false            // true = 打开 WebView2 开发者工具
  },
  "logging": { "level": "INFO", "max_mb": 2, "backups": 3 }
}
```

快捷键写法：`ctrl` / `alt` / `shift` / `win` 任意组合 + 单个字母数字或 `f1`–`f12`、
`space`、`tab`、`enter`、`esc`、`home`、`end` 等，例如 `ctrl+shift+t`。

`state.json`（自动生成）保存结果窗口的位置大小，不用手改。

## 工作原理（为什么这样设计）

1. **取词**：用 `WH_MOUSE_LL` 全局钩子判断“这是一次划选”（左键按下到抬起位移 ≥ 阈值，
   或双击选词），并且按下点必须在窗口**客户区**（落在标题栏/滚动条上不算）。
   然后注入一次 Ctrl+C 把选中内容送进剪贴板，读完文本后还原原剪贴板内容。
   —— 这是 Windows 上唯一对所有程序都通用的取词方式（UI Automation 在浏览器/PDF 阅读器里
   并不可靠）。
2. **不打扰**：弹窗是 `WS_EX_NOACTIVATE + WS_EX_TOOLWINDOW` 的无边框 WebView2 窗口，
   不抢焦点、不进任务栏；弹出后立刻把前台窗口还给用户原来的程序。
3. **渲染**：结果页先把公式和代码抽成占位符，再交给 marked 解析 Markdown，最后用 KaTeX
   渲染公式——这样公式里的 `_`、`*`、`\` 不会被 Markdown 误伤（`$5` 这类货币写法也不会被
   当成公式）。KaTeX、marked 与字体都已随项目离线内置（`web/vendor/`），无网也能渲染。
4. **网络**：TLS 校验收口到 **Windows 证书store**，所以杀毒软件/企业代理做 HTTPS 扫描
   （例如 Kaspersky）时也能正常调用 API。

## 常见问题

**选中文字后没有弹窗？**
- 托盘菜单里「划词翻译」是否被取消勾选；
- 选区是否过短（默认 ≥2 字符）或拖拽距离太小（<5px）；
- 目标程序是否以**管理员身份**运行——普通权限的程序无法向高权限窗口注入 Ctrl+C，
  此时请以管理员身份运行本工具（或改用快捷键 + 手动 Ctrl+C 后用「翻译剪贴板」）；
- **看日志定位**：把 `logging.level` 改成 `DEBUG`，日志里每一次划选都会留下三行线索——
  `capture requested (mode=... reason=drag point=...)`（钩子是否识别到划选）、
  `capture: injecting Ctrl+C into '<窗口标题>' (<窗口类>)`（Ctrl+C 实际发给了哪个窗口，
  如果这不是你划选的那个程序，说明取词瞬间前台窗口被别的程序抢走了）、
  `no text captured (<原因>)`（对方没有把选中内容放进剪贴板）。
  另有 60 秒一次的 `heartbeat` 行，里面的 `hooks`/`worker_alive`/`slow_calls` 可以看出
  全局钩子是否还健康（钩子被系统摘掉或回调过慢时程序会自动重装并记录告警）。

**快捷键没反应？** 在「设置 → 划词与快捷键」确认已启用快捷键，以及组合键没被其他软件占用
（本工具会“吞掉”匹配到的组合键）。在设置窗口修改并保存后会重新注册快捷键。

**任务栏里出现了多余的窗口？** 默认已经全部隐藏：划词弹窗和结果窗口都不出现在任务栏与
Alt+Tab 里（结果窗口从托盘菜单「显示结果窗口」打开）。如果你更希望结果窗口像普通程序那样
出现在任务栏/Alt+Tab 中，把 `ui.result_in_taskbar` 改为 `true` 即可。

**剪贴板里原来的内容不见了？** 默认会还原；只有原剪贴板内容是本工具无法备份的私有格式时
才会放弃还原（日志里会记录）。可在配置里关闭 `restore_clipboard`。

**译文里公式没渲染？** 模型偶尔会把公式写成不带分隔符的裸 LaTeX（源文本本身也可能是这样）。
程序对此有三重保障：提示词要求补全 `$...$`/`$$...$$`；渲染器会自动识别裸 LaTeX 并当公式排版
（同时刻意避开 Windows 路径、`my_file.py` 这类下划线文件名、`$5` 货币、英文里的 `\text{...}`
以及代码块内的 LaTeX）；实在还不渲染就点「重试」，或在 `extra_instructions` 里强调公式写法。

**PDF 复制的公式不是 LaTeX，而且上下标、分式散落到多行？** 直接划选翻译即可，
不需要先转成 LaTeX。应用保留这些行序和 Unicode 上下标信息，让模型结合邻近定义和数学上下文
重构公式、接回正文断行，再用 KaTeX 显示。不会因为复制排版不完整就一律冻结为原始代码。
确实无法恢复的小片段会保留原文；在「更多 → 查看原文」或译文下方可以核对复制文本。
目前重构依据选中的文本，并未自动读取 PDF 文件、页面坐标或截图；选择较完整的公式及相邻
解释通常有利于恢复。数学含义仍需按原页核对，样本测试通过不代表任意 PDF 都能准确恢复。
测试脚本只读取指定源文件，提取文本、真实 API 响应与窗口截图保存在 `logs/`。

**内存/性能**：常驻约 100–150MB（WebView2 占大头），空闲时 CPU 占用可忽略；只有弹窗显示、
翻译进行时才会渲染页面。
