# 划词翻译（Selection Translator）

**极轻便、泛用的翻译！** 科研、代码、日常翻译需求等都能完美满足。最重要的是它随处可用——
你不必为不同场景配置不同的翻译器。

---

## 一、为什么需要它：和普通翻译方式比，好在哪

### 1. 你的 AI 助手在用你看不懂的语言干活时，你随时看得懂它在做什么

比如 DeepSeek、Kimi、Grok 这类会把**思维链**摊开给你看的模型——有时会满屏英文，让人难以知道它在做什么、
做到了哪一步、是不是打算偷懒。以前你得"复制 → 切到翻译网页 → 粘贴 → 等"，
现在**直接划选它、在光标旁点一下**，中文译文当场出现——公式、代码块、表格也会被正确排版，
不会变成一堆看不懂的符号。

它不限于某个程序：无论它躲在终端、IDE、浏览器还是聊天窗口里说话，**划选就能翻**
（拖拽 ≥5px 或双击选词触发）。

### 2. 读科研论文：不用额外工具，打开 PDF 划一段，公式也照样排版

**这大概是它最有趣的用法。** 不用装 Zotero 插件、不用把论文整篇传到翻译网站、也不用截图 OCR。
**划选一段、在光标旁点一下**，一份排版体面的中文译文就直接给你：公式该有的样子一个不少，
标题、列表、表格、代码块也照原样保留，原文随时可以展开对照。

pdf论文里的公式，正是它专门处理过的：它不会把一堆符号原样丢给你，
而是结合上下文还原成数学式；判断不出来的时候也不会乱猜——这类"重建过的公式"会在卡片里
提示「公式已尝试重构 · 对照复制原文」，让你能逐字核对，实在无法还原的碎片则原样留在
标注「结构待核对」的块里。（公式排版用的是离线内置的 KaTeX，不联网、不依赖外部 CDN。）

重建出来的公式如果哪个上下标写反了，右键那一处就能换成正确写法，程序会记住你的选择，
右键候选会按你的习惯排序，不用重译整段。新结果仍默认显示 API 返回的公式。
如果 API 把字母合并进带字体的基底，例如把 `m_{si}` 写成 `\mathit{ms}_i`，右键列表也会提供标注「拆分字母」的候选。选择后可将 `s` 和 `i` 一起放到 `m` 的下标，原有手写公式和历史排序仍会保留。

LaTeX 正文也支持常见排版：`itemize` 显示为项目列表，`enumerate` 显示为编号列表，`description` 保留条目标签，支持列表嵌套。`\textbf`、`\textit`、`\emph` 和常见章节标题会按对应样式显示。翻译保留这些命令并翻译其中的正文，卡片将其转换为现有 Markdown 排版，复制时保留返回的 LaTeX 源码。列表中的公式仍由 KaTeX 渲染并可右键调整。这一支持面向常见正文结构，不运行完整的 LaTeX 文档、自定义宏或宏包。

LaTeX 章节采用三级编号：`\section` 显示 `I.`、`II.`，`\subsection` 显示 `A.`、`B.`，`\subsubsection` 显示 `1)`、`2)`。后二级使用斜体，字号逐级缩小。新上级标题会重置下级编号，带 `*` 的标题不编号。每份选区独立计数，默认从首项开始，选区中显式的 `\setcounter{section}{2}` 可让下一节从 `III.` 开始。普通 Markdown 标题保持原有样式。

显示正文时会处理 `\noindent`、段落换行和常见间距控制，不再把这些命令直接显示出来。常见 TeX 重音及特殊字母会转换为 Unicode，例如 `Damg{\aa}rd--Jurik` 显示为 `Damgård–Jurik`。代码与显式公式会先被保护，这些显示转换不改写复制出的 LaTeX 源码。

### 3. 翻过的内容会记住：不重复等，也不重复花额度

- 同一段文字、同样的设置再翻一次，**本地直接给结果**，卡片底部会写明「**本地缓存 · 未调用 API**」——
  你能一眼看出这次没花钱；
- 新选区完全包含在某条旧原文中时，会尝试沿用旧译文的对应完整句子、段落或列表项，允许正文空格和换行差异。卡片标注「**沿用旧译文 · 本地截取对应部分 · 未调用 API**」。参照可以来自缓存或历史，不限于上次翻译。更大的选区、部分重叠、半句话或对应关系不明确时，正常请求翻译；
- 点「**重新翻译**」不会拿回旧结果：它会**真的重新请求**，并把上一版译文交给模型复查准确性、术语与公式，
  只修真正的问题，不会为了让译文"看起来不同"而乱改措辞或数学；
- 重试前还可以**选择原因**（公式部分未渲染、上下标写法不正确、术语或句意不准确、译文不完整等），
  也可以**自己填写任何个性化意见**，或者跳过不选；这些说明会随重试请求一起发给模型，
  让这一次修改更有针对性、译文更准确；
- 缓存只存本机，默认最多 300 条，按最近使用淘汰，可以在设置里关掉。

子区间复用优先选择覆盖选区的最小上下文。同一原文优先使用历史中保存的当前译文，包括手动调整过的公式。新记录按方向、模型、服务地址、密钥、提示词和生成设置核对兼容性，旧历史仅在模型一致且没有自定义指令时作为候选。关闭本地缓存也会关闭子区间复用。「重新翻译」始终绕过精确缓存和子区间复用。辅助索引保存在现有缓存数据库中，随缓存淘汰并纳入自动数据预算。

### 4. 翻过的东西不会再丢：可搜索、可加标签、可导出

- 翻译完成会自动保存到本机，默认最多 500 条，**退出程序也还在**；
- 卡片「更多 → 查看全部」里有**全文搜索**（原文或译文命中）、**标签**与标签筛选；
  回看时依然用公式排版显示，且不联网；
- 一键**导出**：Markdown（带时间与方向），或 UTF-8、Tab 分隔的**两列文本**，
  直接导入 **Anki / 欧路词典**当词条；清空历史需要二次确认。

### 5. 不打扰：弹窗与卡片都按"静默"设计

- 划词弹窗无边框、置顶，且用 `WS_EX_NOACTIVATE`：**不抢焦点**，弹出后立刻把前台窗口还给你原来的程序；
- 弹窗与结果卡片**不进任务栏、不进 Alt+Tab**（可配置），只留一个托盘图标；
- 结果卡片是**固定大小**（默认占工作区 1/4 × 1/4，如 1920×1032 → 480×258），长译文在卡片内滚动，
  不会突然盖住半个屏幕；出结果时会自动升到最前，但依然不抢焦点；
- 快捷键 `Ctrl+Alt+C` / `Ctrl+Alt+E` 可直接翻译当前选中文字，跳过弹窗。

### 6. 你的文字只去你自己配置的 API

- 没有账号体系、没有遥测、不收集任何使用数据；日志只写本地 `logs/app.log`，**不记录译文正文**；
- 选中文本只发送到**你自己填的** API 地址（默认 DeepSeek），用**你自己的** Key，按量计费；
- 取词时临时按一次 Ctrl+C，**读完立即把原剪贴板内容还原**；
- 缓存、历史与导出文件都只在本机（`local-data/`，已被 Git 忽略，不提交、不上传）；
- 界面资源全部离线内置；卡片**不加载任何外部图片**（图片位置显示 `[图片：替代文本]`），
  链接不会在卡片内打开网页——点击会交给系统默认浏览器（带 `noreferrer`）。

### 7. 可调、可控、开源

模型 / API 地址 / 温度 / 超时 / 重试 / 最大长度都能改；14 套主题、字号、卡片尺寸、快捷键、
自动收起时间、缓存与历史条数都能调。填完 Key 点一下设置里的「**测试连接**」，用当前表单的值
（还没保存也行）就能立刻验证地址与密钥是否可用、有哪些模型、耗时多少——不用等翻译时报错才发现填错。
MIT 许可，单机运行、无服务端。

> 已知限制（提前说明）：仅支持 Windows（依赖 Win32 全局钩子与 WebView2）；
> 需要你自己提供 DeepSeek API Key（本项目不内置、不代付）；以**管理员身份运行**的窗口
> 无法被普通权限的进程取词（Windows 权限隔离，见常见问题）。

## 二、从 GitHub 下载并使用

### 第 1 步：准备环境

| 需要 | 说明 |
| --- | --- |
| Windows 10 / 11 | 仅 Windows |
| Python 3.10 及以上 | 安装时务必勾选 **Add python.exe to PATH** |
| Microsoft Edge WebView2 运行时 | Win10/11 通常已自带；若启动报错，到 [WebView2 下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 |

### 第 2 步：下载本项目

方式 A（推荐，之后可用 `git pull` 更新）：

```bat
git clone https://github.com/AXU464/selection-translator.git
cd selection-translator
```

方式 B（没装 git）：打开仓库页面 → 右上 **Code** → **Download ZIP**，解压到任意目录。

### 第 3 步：安装依赖

```bat
cd <本项目所在目录>
python -m pip install -r requirements.txt
```

依赖只有 5 个：`pywin32`、`requests`、`pywebview`、`pystray`、`pillow`。

### 第 4 步：申请并填写 DeepSeek API Key

1. 打开 <https://platform.deepseek.com/api_keys>（需注册并充值），创建一个 API Key（形如 `sk-…`）；
2. 填进本工具，二选一：
   - **图形化（推荐）**：先启动（下一步），在托盘菜单「**设置与主题**」→「翻译服务」里粘贴 Key → 保存；
     旁边有「测试连接」，点一下就知道填对没有；
   - **手动**：把 `config.example.json` 复制为 `config.json`，把 `api.api_key` 填上。

`config.json` 已被 `.gitignore` 忽略，**不会**被提交或上传；仓库里只有不含密钥的
`config.example.json` 模板。

### 第 5 步：启动

- 双击 **`run.vbs`** —— 无控制台窗口，日常使用推荐；
- 或双击 **`run.bat`** / 命令行 `python main.py` —— 带控制台，排错时用。

首次启动后，托盘区会出现「**译**」图标（若没看到，点任务栏的「^」展开隐藏图标）。

> 首次运行会把本工具加入开机自启（在「启动」文件夹放一个快捷方式）。
> 不需要的话，托盘菜单里取消勾选「**开机自启**」即可，之后不会再自动加回。

### 第 6 步：开始使用

1. 在任意程序里用鼠标**划选**一段文字（拖拽 ≥5px，或双击选词）；
2. 选区旁会弹出 `Translate into Chinese` / `Translate into English`，点一个；
3. 译文出现在结果卡片里，公式与排版都已渲染好。

关闭卡片只是隐藏，程序仍在托盘运行；需要再打开时用托盘菜单「**显示结果窗口**」。

## 三、使用说明

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+C` | 把当前选中的文字译成中文（跳过弹窗，直接出结果） |
| `Ctrl+Alt+E` | 把当前选中的文字译成英文 |

两个快捷键都可以在设置窗口里改（也可关闭）。注意：匹配到快捷键时本工具会"吞掉"该组合键，
避免误触发别的软件。

### 托盘菜单

| 菜单项 | 作用 |
| --- | --- |
| **划词翻译** | 勾选 = 启用划词检测；取消 = 暂停（同时停用快捷键） |
| **翻译剪贴板 → 中文 / English** | 直接翻译剪贴板里的文本，不依赖划词 |
| **显示结果窗口** | 重新打开结果卡片 |
| **设置与主题** | 打开可视化设置窗口 |
| **打开日志目录** | 打开 `logs/`，排错用 |
| **开机自启** | 添加/移除「启动」文件夹里的快捷方式 |
| **退出** | 真正结束程序 |

### 结果卡片

- **拖动**：按住卡片顶部标题栏拖动；**缩放**：拖四条边或四个角（八向拉伸）；
- **「更多」按钮**（卡片右上角）：展开二级面板，里面有 放大 / 缩小 / 默认尺寸 / 关闭，
  以及 原文、复制、⇄ 反向、重新翻译、设置、日志；
- 「**原文**」可展开你复制的那段原文做对照；原文含公式时按纯文本显示，方便逐字核对；
- 卡片底部会显示本次结果的状态：正常翻译会写模型与 token 用量；**命中缓存会写「本地缓存 · 未调用 API」**；
- 卡片顶部有最近 40 条的下拉，可以直接回看；
- 长译文在卡片内滚动，鼠标滚轮可用；卡片大小与位置会被记住（「默认尺寸」可恢复 1/4 工作区）。

### 历史与导出

- 入口：卡片「更多 → **查看全部 · 搜索、标签与导出**」，或设置窗口的「**历史与导出**」页；
- **搜索**：关键词命中原文或译文即可；**标签**：给某条加上逗号分隔的标签，也可按标签筛选；
- **回看**：用与卡片相同的公式排版显示原文与译文，**不调用 API、不联网**；
- **导出当前筛选结果**：
  - **Markdown**：带 UTC 时间与方向，保留原文排版；
  - **两列文本**：UTF-8、Tab 分隔，第一列原文、第二列译文，标签附在译文末尾——导入
    **Anki / 欧路词典**时选择对应的两列字段即可（为保持两列格式，换行与 Tab 会被整理成空格）；
  - 导出文件放在 `local-data/exports/`，历史页里有「打开导出文件夹」；
- **清空历史**需要二次确认，会同时清除标签；独立缓存与已导出的文件不受影响。

### 公式随手改，越用越顺手

从 PDF 复制出来的公式，上下标经常分不清。把鼠标放到公式上，右键那一处，就能从实际排版的候选里
挑出正确的上标、下标或嵌套写法。每处独立，改一处不影响别处；选错了再选一次即可。改完立即生效，
复制和导出都是你当前看到的样子。

候选项里没有想要的，最后一项可以直接写 LaTeX（不用带 `$`、`$$` 等定界符），边输入边预览。
希腊字母、分式、根号、集合括号里的变量也能单独调整。

程序会记住你选过的写法，下次把常选的候选排在前面。默认显示保持 API 返回的公式，只有你点选候选后
才替换这一处。已经保存的历史保留上次修改。想重新开始，可以在设置 →「公式与存储」里清除学习记录。

### 中文统一，排版不动

中文译文自动统一为简体，旧缓存和历史也按简体显示；公式、代码、
文件路径、链接和原文保持原样。转换在本机完成，不联网。

### 重试可以说得更具体

「更多」里的重试按钮上方可以选择原因，比如「公式部分未渲染」「上下标写法不正确」，也可以写下
自己的意见，让模型知道这一遍该往哪里改。

中文正文里疑似残留普通英文时，卡片会提示「可能有正文漏译」。点击可打开带具体检查意见的重试面板，
再由你决定是否请求。检查在本机完成，不自动追加 API 调用，也不改动公式、代码或专有名称。复杂 PDF
公式的重构仍可能需要对照原文，使用右键候选或手写 LaTeX 修正。

### 本地数据不会无限增长

日志、缓存、历史和公式学习记录合计不超过 1GB，接近上限会自动清理；你自己导出的文件不会被动，
设置页能看到各自占用了多少。

### 设置窗口

从卡片的「更多 → 设置」或托盘的「设置与主题」打开，分五页：

- **外观与阅读**：跟随系统，以及雾白、暖砂、冰川、青瓷、樱花、藤萝、奶油、银灰、钴蓝、赤陶、碧湾、石墨、莓酒、荧光 14 套主题；
  字号可即时预览；
- **翻译服务**：API Key、**测试连接**、模型、流式输出、**本地缓存**（开关与条数）、深度思考、额外翻译要求；
  高级区域还有 API 地址、温度、输出上限、超时、重试；
- **划词与快捷键**：划词检测、双击选词、剪贴板恢复、按钮自动收起时间、选区字符上限、中英文快捷键；
- **历史与导出**：查看历史、全文搜索、标签筛选、Markdown／两列文本导出、确认清空与条数上限。
- **公式与存储**：公式右键修改、裸 LaTeX、键盘说明、学习清除和自动数据／导出文件占用。

### 配置（config.json）

需要调整设置窗口里没有的选项时，直接编辑 `config.json` 后重启。常用项：

```jsonc
{
  "api": {
    "base_url": "https://api.deepseek.com",
    "api_key": "sk-...",              // 你的 DeepSeek Key
    "model": "deepseek-flash",        // 也可换成 deepseek-v4-pro
    "thinking": false,                // false = 关闭思考链，翻译更快
    "stream": true,                   // 流式输出（边翻边显示）
    "max_tokens": 16000,
    "extra_instructions": ""          // 追加给模型的额外要求，如术语表
  },
  "behavior": {
    "detect_selection": true,         // 划词总开关
    "double_click_select": true,      // 双击选词也弹按钮
    "min_chars": 2,                   // 少于这么多字符不弹按钮
    "drag_threshold_px": 5,           // 拖拽多少像素算划选
    "max_chars": 12000,               // 超长选区截断上限
    "restore_clipboard": true,        // 取词后还原原剪贴板
    "auto_dismiss_seconds": 9,        // 弹窗自动收起秒数（0 = 不自动收起）
    "hotkey_chinese": "ctrl+alt+c",
    "hotkey_english": "ctrl+alt+e",
    "hotkey_enabled": true
  },
  "cache": {
    "enabled": true,                  // 本地翻译缓存（命中时卡片显示「本地缓存 · 未调用 API」）
    "max_entries": 300                // 最多缓存多少条（10–5000），按最近使用淘汰
  },
  "history": {
    "max_entries": 500                // 历史最多保留多少条（10–5000）
  },
  "ui": {
    "theme": "system",                // system 或 themes.json 里的主题 ID
    "font_size": 14,
    "result_on_top": false,           // 结果卡片是否置顶
    "fit_to_content": false,          // true = 短译文时自动收缩卡片高度
    "result_in_taskbar": false,       // false = 卡片不进任务栏/Alt+Tab
    "debug_webview": false            // true = 打开 WebView2 开发者工具
  },
  "logging": { "level": "INFO", "max_mb": 2, "backups": 3 }
}
```

`state.json`（自动生成）记录卡片的位置与大小，不用手改。

## 四、工作原理

1. **取词**：用 `WH_MOUSE_LL` 全局钩子判断"这是一次划选"（左键按下到抬起位移 ≥ 阈值，或双击选词），
   且按下点必须在**客户区**（落在标题栏/滚动条上的拖拽不算）。然后注入一次 Ctrl+C 把选中内容
   送进剪贴板，读完文本后还原原剪贴板——这是 Windows 上唯一对所有程序都通用的取词方式。
   取词前会校验前台窗口就是划词时那个窗口，注入后再校验一次，不一致就放弃，宁可不翻也不翻错。
2. **不打扰**：弹窗是 `WS_EX_NOACTIVATE + WS_EX_TOOLWINDOW` 的无边框 WebView2 窗口，
   不抢焦点、不进任务栏；出结果时用 `SWP_NOACTIVATE` 把卡片提到最前，也不夺焦点。
3. **渲染**：结果页先把公式和代码抽成占位符，再交给 marked 解析 Markdown，最后用 KaTeX 渲染公式，
   所以公式里的 `_`、`*`、`\` 不会被 Markdown 误伤，`$5`、`$1,234.00` 这类货币也不会被当成公式。
4. **文档预处理**：PDF 复制文本里的连字（ﬁ/ﬂ）、软连字符、缺失字形会被修复或显式标记出来，
   但**不会**在这一层去猜指数/分式——把判断留给模型，并把"这里可能不可靠"告诉用户。
5. **网络**：TLS 校验使用 **Windows 证书store**，所以杀毒软件/企业代理做 HTTPS 扫描
   （如 Kaspersky）时也能正常调用 API，无需额外配置证书。
6. **本地数据**：缓存与历史都放在项目目录下的 `local-data/`（该目录已被 Git 忽略，不提交、不上传）：
   - 缓存是一个 SQLite 文件，键里包含原文、方向、服务地址、密钥、模型以及全部影响输出的生成参数，
     **其中任何一项变化都会重新翻译**；按最近使用淘汰，存储异常时仅本次运行停用缓存并记日志；
   - 历史是按行保存的 JSONL，写入用临时文件原子替换，中断残留的 `.pending` 文件会在下次启动时合并恢复，
     坏行会被跳过且原文保留；读写不可用时提示并降级为内存记录；
   - 导出文件在 `local-data/exports/`。这些内容都不会被写进日志正文。

## 六、常见问题与解决方法

### 安装与启动

**Q：命令行提示 `python` 不是内部或外部命令。**
没装 Python 或安装时没勾 PATH。重新安装并勾选 **Add python.exe to PATH**；或用 `py -3` 代替 `python`。

**Q：启动时报缺少 WebView2 / 窗口空白。**
安装 [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) 后重试。

**Q：双击 `run.vbs` 似乎没反应。**
1）可能已经在运行（本工具是单实例，重复启动会提示）；看托盘有没有「译」图标；
2）用 `run.bat` 启动可以看到控制台报错；
3）查看 `logs/app.log`。
若日志里出现 `SetWindowsHookExW ... failed`，多为安全软件拦截全局钩子，把本工具加入白名单后重试。

**Q：托盘里找不到图标。**
Win11 默认折叠隐藏图标：点任务栏右侧的「^」展开，把「译」拖到常显区。

**Q：怎么卸载？**
托盘菜单「退出」→ 删除本目录 →（如果开过自启）删除「启动」文件夹里的 `划词翻译.lnk`；
Python 依赖用 `python -m pip uninstall pywin32 requests pywebview pystray pillow` 清理（可选）。
如果想连本地数据一起清掉，删除目录里的 `local-data/` 即可。

### 划词与取词

**Q：划选文字后没有弹出按钮？** 逐条排查：
1. 托盘菜单里「划词翻译」是否被取消勾选了；
2. 选区是否过短（默认 ≥2 字符）或拖拽距离太小（默认 <5px 不出按钮）；
3. 目标程序是否以**管理员身份**运行——普通权限进程无法向高权限窗口注入 Ctrl+C。
   要么以管理员身份运行本工具，要么改用「手动 Ctrl+C 后 → 托盘菜单『翻译剪贴板』」；
4. 把 `logging.level` 改成 `DEBUG` 后看 `logs/app.log`：每次划选都会留下线索——
   `capture requested (...)`（钩子是否识别到划选）、
   `capture: injecting Ctrl+C into '<窗口标题>'`（Ctrl+C 实际发给了哪个窗口，
   若不是你划选的那个程序，说明取词瞬间前台窗口被别的程序抢走了）、
   `no text captured (<原因>)`（对方没有把选中内容放进剪贴板）；
   另有 60 秒一次的 `heartbeat` 行，可看全局钩子是否健康（本工具会自动重装失效的钩子并记录告警）。

**Q：双击选词不出按钮？** 确认 `behavior.double_click_select` 为 `true`；或用拖拽划选。

**Q：快捷键没反应？**
确认设置里「快捷键」页的开关是开的；可能被其它软件占用（例如截图、输入法、IDE 的同类组合），
换一个组合即可。改完配置后，从托盘菜单取消再勾选一次「划词翻译」以重新注册。

### 翻译与渲染

**Q：翻译失败，提示 401 / 余额不足 / 超时。**
401 = API Key 无效或未授权；余额不足 = 去 DeepSeek 平台充值；
超时/网络错误 = 检查网络与代理。报错信息会显示在结果卡片里，点「重新翻译」可再试一次。

**Q：设置里「测试连接」显示正常，翻译却还是失败？**
「测试连接」只验证**地址能连、密钥有效、能列出模型**（几秒内出结果，不修改配置、不发送待翻译正文）。
余额不足、触发限流、或某个模型暂时不可用，只有真正翻译时才会暴露。

**Q：提示 TLS 证书校验失败。**
这是杀毒软件/企业代理做了 HTTPS 扫描。本工具已经改用 Windows 证书store 校验，正常情况无需配置；
若仍失败，把本工具或 `api.deepseek.com` 加入安全软件白名单。

**Q：译文里的公式还是没排版出来？**
先点卡片里的「**重新翻译**」；仍不行时，在 `api.extra_instructions` 里强调
"所有公式必须用 $...$ 或 $$...$$ 包裹"，或在设置窗口的「翻译服务 → 额外翻译要求」里填写。

**Q：出现了「公式已尝试重构 · 对照复制原文」提示。**
说明这段原文是从 PDF 复制来的、排版已丢失，模型按上下文重建了公式。**请对照原文核对**：
展开卡片的「原文」可以看到复制时的原始形态。

**Q：出现「选中语言类型与目标一致」。**
这是**本地**判定：选区里出现拉丁字母就会被当作英文（中文里夹带公式、变量时也会如此），
所以「译成英文」会被拦下——好处是不消耗 API 额度。确实需要翻译时，只选中文部分，
或换成另一个方向。

**Q：为什么同一段文字第二次翻是秒出的？**
它命中了本地缓存，卡片底部会写「本地缓存 · 未调用 API」表示这次没有请求接口。
缓存键包含原文、方向、服务地址、密钥、模型与全部生成参数，任何一项变了都会重新翻译；
不想要缓存可以在设置里关掉，或调小条数。

**Q：我点了「重新翻译」，会不会又拿回旧结果？**
不会。「重新翻译」**始终跳过缓存**，重新请求接口；如果你上次是翻译失败，它就直接重发；
如果你是对译文不满意，它会把上一版译文一起交给模型复查（准确性、术语、公式），
只修正真正的问题，并且**不会为了让译文看起来不同而故意改措辞或数学**——
所以如果上一版本来就是对的，新结果可能和它一样。重译成功后，新结果会**覆盖**该段文字的缓存。

**Q：想换模型 / 用自己的中转地址。**
设置窗口 →「翻译服务」→ 高级区域里改 `model` 与 `base_url`（也可直接改 `config.json`）。

### 窗口与外观

**Q：卡片太大/太小，或者挡住了正在看的内容。**
拖动标题栏移动、拖边缘缩放；「更多 → 默认尺寸」恢复为工作区 1/4；尺寸与位置会被记住。
想让卡片始终在最前，把 `ui.result_on_top` 设为 `true`。

**Q：卡片被别的窗口挡住、Alt+Tab 里找不到。**
这是"静默"设计（默认不进任务栏/Alt+Tab）。用托盘菜单「显示结果窗口」即可唤回；
想让卡片像普通程序一样出现在任务栏，把 `ui.result_in_taskbar` 设为 `true`。

**Q：关掉卡片后，划词按钮又冒出来了？**
这是刻意设计：关闭卡片 = 回到"已选中"状态，方便你换个方向再翻一次。
不想看到按钮时按 `Esc` 收起，或点托盘菜单暂停划词。

**Q：译文被我误关了 / 想回看之前翻过的内容。**
卡片「更多」里有最近 40 条的下拉；「查看全部 · 搜索、标签与导出」可看完整历史（默认保留 500 条）。
注意：启用本功能之后完成的翻译才会保存；更早的版本只把历史放在内存里，那部分无法追溯恢复。

### 数据与隐私

**Q：缓存和历史存在哪？会上传吗？**
都在项目目录的 `local-data/` 里：缓存 `cache.sqlite3`、历史 `history.jsonl`、导出 `exports/`。
该目录已被 Git 忽略，**不会提交、不会上传**；译文也不会被写进日志正文。
不想要它们：设置里关掉缓存、清空历史，或直接删掉 `local-data/`（会自动重建）。

**Q：怎么把历史导出到 Anki / 欧路？**
在「历史与导出」里点导出两列文本：UTF-8、Tab 分隔，第一列原文、第二列译文，标签附在译文末尾。
导入时选对应的两列字段即可（为保持两列格式，换行与 Tab 会被整理成空格）。

**Q：剪贴板里原来复制的内容不见了？**
默认会还原；只有原剪贴板内容是本工具无法备份的私有格式时才会放弃还原（日志中会记录）。
可在设置里关闭 `restore_clipboard`。

### 其它

**Q：为什么开机后它自己启动了？**
首次运行会自动加入开机自启（如前文所述）。不想保留：托盘菜单取消「开机自启」，并删除
「启动」文件夹中的 `划词翻译.lnk`。

**Q：资源占用大吗？**
常驻约 100–150MB（WebView2 占大头），空闲时 CPU 占用可忽略；只有显示弹窗、翻译进行中才渲染页面。
