# 划词翻译（Selection Translator）

在**任意 Windows 程序**里用鼠标划选一段文字，光标旁立刻弹出「译成中文 / 译成英文」两个按钮，
点击即可得到**保留 Markdown 排版与 LaTeX 公式**的译文——公式会被真正排版出来，而不是显示成
`\bar{\psi}\gamma^\mu` 这种源码。

常驻托盘，不抢焦点、不进任务栏、不打断你正在读的东西。

设置 → 翻译服务中的「测试连接」使用当前表单（无需先保存），显示连接结果、模型列表与耗时。留空密钥会使用已保存的密钥；最多等待约 5 秒，不会改写配置或发送翻译正文。该测试检查模型列表接口，不代表余额充足或某个模型一定可以生成译文。

本地翻译缓存默认开启，最多 300 条（设置 → 翻译服务可关闭或调整）。同一原文、方向、服务地址、密钥与生成请求完全一致时，复用结果并显示「本地缓存 · 未调用 API」。模型、温度、额外要求、提示词、PDF 预处理结果等变化都会重新翻译。数据位于被 Git 忽略的 `local-data/cache.sqlite3`，按最近使用淘汰；存储异常时本次运行停用缓存，原文件保留。

「重新翻译」始终绕过缓存读取，成功后替换旧缓存。对已成功的结果重译时，会把旧译文交给模型重新检查准确性、术语和公式；技术性失败后则直接重发。不会提高随机性或强求不同措辞，因此正确的译文仍可能不变。

历史现在自动保存在本机，默认最多 500 条。入口是卡片「更多 → 查看全部 · 搜索、标签与导出」，或设置窗口「历史与导出」。可搜索原文／译文、添加逗号分隔的标签、按标签筛选、回看原文与译文；「在卡片查看」会使用原有公式排版，不调用 API。卡片内的快捷下拉保留最近 40 条，完整记录在历史页面分页展示。

导出当前筛选结果为带 UTC 时间与方向的 Markdown，或 UTF-8、Tab 分隔的两列文本。两列分别为原文和译文，标签附在译文末尾；导入 Anki／欧路时选择对应的两列字段。为保持两列格式，换行与 Tab 会整理为空格，标签不是 Anki 独立标签字段；Markdown 保留原文排版。导出文件在 `local-data/exports/`，可点击「打开导出文件夹」。

历史文件 `local-data/history.jsonl` 按行保存，缺失时从空记录开始，坏行跳过且保留原始内容；写入用临时文件原子替换，中断留下的 `.pending` 文件下次会合并恢复。不能读写时会显示提示并降级为内存记录。清空需要二次确认，清除历史、标签及坏行；独立缓存和已导出文件不受影响。以上本地数据、临时文件和导出目录均被 Git 忽略，不上传、不记入正文日志。

为避免回看内容触发额外联网，Markdown 图片显示替代文本，链接只显示文字与悬停地址，不在卡片内加载外部页面。公式字体与排版资源都来自本地。

## 一、为什么需要它：和普通翻译方式比，好在哪

### 1. 任何程序里划词就能翻，不限于浏览器

网页翻译、浏览器插件只能在浏览器里工作；PDF 阅读器、Word、VS Code、CAD、文献管理器、
桌面软件里的文字它们都拿不到。本工具用全局鼠标钩子识别划选（拖拽 ≥5px 或双击选词），
**系统里任何窗口**都能用。

### 2. 公式不丢：这是它和几乎所有划词翻译工具的核心区别

普通划词翻译拿到公式往往给出：

| 你看到的原文 | 普通工具的译文 | 本工具的译文 |
| --- | --- | --- |
| `$$\mathcal{L} = \bar{\psi}(i\gamma^\mu \partial_\mu - m)\psi$$` | 原样一堆反斜杠，或删掉符号 | 正常排版的公式（花体 𝓛、带上横线的 ψ̄、上下标） |
| 从 PDF 复制出来的 `Y`（其实是 ∏）、`N 2`（其实是 N²）、被拆到下一行的上下标 | 完全看不懂 | 结合上下文重建为 `\prod`、`N^2`、正确的上下标 |
| Markdown 的标题/列表/表格/代码块 | 结构被拍平 | 结构保留，代码块原样不动 |



### 3. 不打扰：弹窗与卡片都按"静默"设计

- 划词弹窗无边框、置顶，且用 `WS_EX_NOACTIVATE`：**不抢焦点**，弹出后立刻把前台窗口还给你原来的程序；
- 弹窗与结果卡片**不进任务栏、不进 Alt+Tab**（可配置），只留一个托盘图标；
- 结果卡片是**固定大小**（默认占工作区 1/4 × 1/4，如 1920×1032 → 480×258），长译文在卡片内滚动，
  不会突然盖住半个屏幕；出结果时会自动升到最前，但依然不抢焦点；
- 快捷键 `Ctrl+Alt+C` / `Ctrl+Alt+E` 可直接翻译当前选中文字，跳过弹窗。

### 4. 你的文字只去你自己配置的 API

- 没有账号体系、没有遥测、不收集任何使用数据；日志只写本地 `logs/app.log`；
- 选中文本只发送到**你自己填的** API 地址（默认 DeepSeek），用**你自己的** Key，按量计费；
- 取词时临时按一次 Ctrl+C，**读完立即把原剪贴板内容还原**；
- 界面资源全部离线内置，运行期不访问任何第三方 CDN。

### 5. 可调、可控、开源

模型 / API 地址 / 温度 / 超时 / 重试 / 最大长度都能改；14 套主题、字号、卡片尺寸、
快捷键、自动收起时间可调；MIT 许可，单机运行、无服务端。

> 已知限制（提前说明）：仅支持 Windows（依赖 Win32 全局钩子与 WebView2）；
> 需要你自己提供 DeepSeek API Key（本项目不内置、不代付）；以**管理员身份运行**的窗口
> 无法被普通权限的进程取词（Windows 权限隔离，见常见问题）。

## 二、从 GitHub 下载并使用

### 第 1 步：准备环境

| 需要 | 说明 |
| --- | --- |
| Windows 10 / 11 | 仅 Windows |
| Python 3.10 及以上 | 安装时务必勾选 **Add python.exe to PATH** |
| Microsoft Edge WebView2 运行时 | Win10/11 通常已自带；若启动报错，到 [WebView2 下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 |

### 第 2 步：下载本项目

方式 A（推荐，之后可用 `git pull` 更新）：

```bat
git clone https://github.com/AXU464/selection-translator.git
cd selection-translator
```

方式 B（没装 git）：打开仓库页面 → 右上 **Code** → **Download ZIP**，解压到任意目录。

### 第 3 步：安装依赖

```bat
cd <本项目所在目录>
python -m pip install -r requirements.txt
```

依赖只有 5 个：`pywin32`、`requests`、`pywebview`、`pystray`、`pillow`。

### 第 4 步：申请并填写 DeepSeek API Key

1. 打开 <https://platform.deepseek.com/api_keys>（需注册并充值），创建一个 API Key（形如 `sk-…`）；
2. 填进本工具，二选一：
   - **图形化（推荐）**：先启动（下一步），在托盘菜单「**设置与主题**」→「翻译服务」里粘贴 Key → 保存；
   - **手动**：把 `config.example.json` 复制为 `config.json`，把 `api.api_key` 填上。

`config.json` 已被 `.gitignore` 忽略，**不会**被提交或上传；仓库里只有不含密钥的
`config.example.json` 模板。

### 第 5 步：启动

- 双击 **`run.vbs`** —— 无控制台窗口，日常使用推荐；
- 或双击 **`run.bat`** / 命令行 `python main.py` —— 带控制台，排错时用。

首次启动后，托盘区会出现「**译**」图标（若没看到，点任务栏的「^」展开隐藏图标）。

> 首次运行会把本工具加入开机自启（在「启动」文件夹放一个快捷方式）。
> 不需要的话，托盘菜单里取消勾选「**开机自启**」即可，之后不会再自动加回。

### 第 6 步：开始使用

1. 在任意程序里用鼠标**划选**一段文字（拖拽 ≥5px，或双击选词）；
2. 选区旁会弹出 `Translate into Chinese` / `Translate into English`，点一个；
3. 译文出现在结果卡片里，公式与排版都已渲染好。

关闭卡片只是隐藏，程序仍在托盘运行；需要再打开时用托盘菜单「**显示结果窗口**」。

## 三、使用说明

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+C` | 把当前选中的文字译成中文（跳过弹窗，直接出结果） |
| `Ctrl+Alt+E` | 把当前选中的文字译成英文 |

两个快捷键都可以在设置窗口里改（也可关闭）。注意：匹配到快捷键时本工具会"吞掉"该组合键，
避免误触发别的软件。

### 托盘菜单

| 菜单项 | 作用 |
| --- | --- |
| **划词翻译** | 勾选 = 启用划词检测；取消 = 暂停（同时停用快捷键） |
| **翻译剪贴板 → 中文 / English** | 直接翻译剪贴板里的文本，不依赖划词 |
| **显示结果窗口** | 重新打开结果卡片 |
| **设置与主题** | 打开可视化设置窗口 |
| **打开日志目录** | 打开 `logs/`，排错用 |
| **开机自启** | 添加/移除「启动」文件夹里的快捷方式 |
| **退出** | 真正结束程序 |

### 结果卡片

- **拖动**：按住卡片顶部标题栏拖动；**缩放**：拖四条边或四个角（八向拉伸）；
- **「更多」按钮**（卡片右上角）：展开二级面板，里面有 放大 / 缩小 / 默认尺寸 / 关闭，
  以及 原文、复制、⇄ 反向、重试、设置、日志；
- 「**原文**」可展开你复制的那段原文做对照；原文含公式时按纯文本显示，方便逐字核对；
- 长译文在卡片内滚动，鼠标滚轮可用；卡片大小与位置会被记住（「默认尺寸」可恢复 1/4 工作区）。

### 设置窗口

从卡片的「更多 → 设置」或托盘的「设置与主题」打开，分四页：

- **外观与阅读**：跟随系统，以及雾白、暖砂、冰川、青瓷、樱花、藤萝、奶油、银灰、钴蓝、赤陶、碧湾、石墨、莓酒、荧光 14 套主题；
  字号可即时预览；
- **翻译服务**：API Key、测试连接、模型、流式输出、本地缓存、深度思考、额外翻译要求；高级区域还有 API 地址、温度、输出上限、超时、重试；
- **划词与快捷键**：划词检测、双击选词、剪贴板恢复、按钮自动收起时间、选区字符上限、中英文快捷键。
- **历史与导出**：查看历史、全文搜索、标签筛选、Markdown／两列文本导出、确认清空与条数上限。

密钥不会回填到页面（留空保存 = 保持原密钥不变）；「取消」/Esc/关闭窗口会撤销未保存的预览；
校验不通过会提示修正，保存失败不会写入半份配置。

### 配置（config.json）

需要调整设置窗口里没有的选项时，直接编辑 `config.json` 后重启。常用项：

```jsonc
{
  "api": {
    "base_url": "https://api.deepseek.com",
    "api_key": "sk-...",              // 你的 DeepSeek Key
    "model": "deepseek-flash",        // 也可换成 deepseek-v4-pro
    "thinking": false,                // false = 关闭思考链，翻译更快
    "stream": true,                   // 流式输出（边翻边显示）
    "max_tokens": 16000,
    "extra_instructions": ""          // 追加给模型的额外要求，如术语表
  },
  "behavior": {
    "detect_selection": true,         // 划词总开关
    "double_click_select": true,      // 双击选词也弹按钮

    "drag_threshold_px": 5,           // 拖拽多少像素算划选

    "restore_clipboard": true,        // 取词后还原原剪贴板
    "auto_dismiss_seconds": 9,        // 弹窗自动收起秒数（0 = 不自动收起）
    "hotkey_chinese": "ctrl+alt+c",
    "hotkey_english": "ctrl+alt+e",
    "hotkey_enabled": true
  },
  "ui": {
    "theme": "system",                // system 或 themes.json 里的主题 ID
    "font_size": 14,
```

## 四、工作原理（为什么这样设计）

1. **取词**：用 `WH_MOUSE_LL` 全局钩子判断"这是一次划选"（左键按下到抬起位移 ≥ 阈值，或双击选词），
   且按下点必须在**客户区**（落在标题栏/滚动条上的拖拽不算）。然后注入一次 Ctrl+C 把选中内容
   送进剪贴板，读完文本后还原原剪贴板——这是 Windows 上唯一对所有程序都通用的取词方式。
   取词前会校验前台窗口就是划词时那个窗口，注入后再校验一次，不一致就放弃，宁可不翻也不翻错。
2. **不打扰**：弹窗是 `WS_EX_NOACTIVATE + WS_EX_TOOLWINDOW` 的无边框 WebView2 窗口，
   不抢焦点、不进任务栏；出结果时用 `SWP_NOACTIVATE` 把卡片提到最前，也不夺焦点。
3. **渲染**：结果页先把公式和代码抽成占位符，再交给 marked 解析 Markdown，最后用 KaTeX 渲染公式
   （见上文"公式不丢"）。
4. **文档预处理**：PDF 复制文本里的连字（ﬁ/ﬂ）、软连字符、缺失字形会被修复或显式标记出来，
   但**不会**在这一层去猜指数/分式——把判断留给模型，并把"这里可能不可靠"告诉用户。
5. **网络**：TLS 校验使用 **Windows 证书store**，所以杀毒软件/企业代理做 HTTPS 扫描
   （如 Kaspersky）时也能正常调用 API，无需额外配置证书。

## 六、常见问题与解决方法

### 安装与启动

**Q：命令行提示 `python` 不是内部或外部命令。**
没装 Python 或安装时没勾 PATH。重新安装并勾选 **Add python.exe to PATH**；或用 `py -3` 代替 `python`。

**Q：启动时报缺少 WebView2 / 窗口空白。**
安装 [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) 后重试。

**Q：双击 `run.vbs` 似乎没反应。**
1）可能已经在运行（本工具是单实例，重复启动会提示）；看托盘有没有「译」图标；
2）用 `run.bat` 启动可以看到控制台报错；
3）查看 `logs/app.log`。
若日志里出现 `SetWindowsHookExW ... failed`，多为安全软件拦截全局钩子，把本工具加入白名单后重试。

**Q：托盘里找不到图标。**
Win11 默认折叠隐藏图标：点任务栏右侧的「^」展开，把「译」拖到常显区。

**Q：怎么卸载？**
托盘菜单「退出」→ 删除本目录 →（如果开过自启）删除「启动」文件夹里的 `划词翻译.lnk`；
Python 依赖用 `python -m pip uninstall pywin32 requests pywebview pystray pillow` 清理（可选）。

### 划词与取词

**Q：划选文字后没有弹出按钮？** 逐条排查：
1. 托盘菜单里「划词翻译」是否被取消勾选了；
2. 选区是否过短（默认 ≥2 字符）或拖拽距离太小（默认 <5px 不出按钮）；
3. 目标程序是否以**管理员身份**运行——普通权限进程无法向高权限窗口注入 Ctrl+C。
   要么以管理员身份运行本工具，要么改用「手动 Ctrl+C 后 → 托盘菜单『翻译剪贴板』」；
4. 把 `logging.level` 改成 `DEBUG` 后看 `logs/app.log`：每次划选都会留下线索——
   `capture requested (...)`（钩子是否识别到划选）、
   `capture: injecting Ctrl+C into '<窗口标题>'`（Ctrl+C 实际发给了哪个窗口，
   若不是你划选的那个程序，说明取词瞬间前台窗口被别的程序抢走了）、
   `no text captured (<原因>)`（对方没有把选中内容放进剪贴板）；
   另有 60 秒一次的 `heartbeat` 行，可看全局钩子是否健康（本工具会自动重装失效的钩子并记录告警）。

**Q：双击选词不出按钮？** 确认 `behavior.double_click_select` 为 `true`；或用拖拽划选。

**Q：快捷键没反应？**
确认设置里「快捷键」页的开关是开的；可能被其它软件占用（例如截图、输入法、IDE 的同类组合），
换一个组合即可。改完配置后，从托盘菜单取消再勾选一次「划词翻译」以重新注册。

### 翻译与渲染

**Q：翻译失败，提示 401 / 余额不足 / 超时。**
401 = API Key 无效或未授权；余额不足 = 去 DeepSeek 平台充值；
超时/网络错误 = 检查网络与代理。报错信息会显示在结果卡片里，点「重试」可再试一次。

**Q：提示 TLS 证书校验失败。**
这是杀毒软件/企业代理做了 HTTPS 扫描。本工具已经改用 Windows 证书store 校验，正常情况无需配置；
若仍失败，把本工具或 `api.deepseek.com` 加入安全软件白名单。

**Q：译文里的公式还是没排版出来？**
先点卡片里的「**重试**」；仍不行时，在 `api.extra_instructions` 里强调
"所有公式必须用 $...$ 或 $$...$$ 包裹"，或在设置窗口的「翻译服务 → 额外翻译要求」里填写。

**Q：出现了「公式已尝试重构 · 对照复制原文」提示。**
说明这段原文是从 PDF 复制来的、排版已丢失，模型按上下文重建了公式。**请对照原文核对**：
展开卡片的「原文」可以看到复制时的原始形态。

**Q：出现「选中语言类型与目标一致」。**
这是**本地**判定：选区里出现拉丁字母就会被当作英文（中文里夹带公式、变量时也会如此），
所以「译成英文」会被拦下——好处是不消耗 API 额度。确实需要翻译时，只选中文部分，
或换成另一个方向。

**Q：想换模型 / 用自己的中转地址。**
设置窗口 →「翻译服务」→ 高级区域里改 `model` 与 `base_url`（也可直接改 `config.json`）。

### 窗口与外观

**Q：卡片太大/太小，或者挡住了正在看的内容。**
拖动标题栏移动、拖边缘缩放；「更多 → 默认尺寸」恢复为工作区 1/4；尺寸与位置会被记住。
想让卡片始终在最前，把 `ui.result_on_top` 设为 `true`。

**Q：卡片被别的窗口挡住、Alt+Tab 里找不到。**
这是"静默"设计（默认不进任务栏/Alt+Tab）。用托盘菜单「显示结果窗口」即可唤回；
想让卡片像普通程序一样出现在任务栏，把 `ui.result_in_taskbar` 设为 `true`。

**Q：关掉卡片后，划词按钮又冒出来了？**
这是刻意设计：关闭卡片 = 回到"已选中"状态，方便你换个方向再翻一次。
不想看到按钮时按 `Esc` 收起，或点托盘菜单暂停划词。

**Q：译文被我误关了 / 想回看之前翻过的内容。**
卡片「更多」里可回看最近翻译；「查看全部 · 搜索、标签与导出」可管理持久化历史。新版本启用后完成的翻译会自动保存，退出后仍保留；旧版本已退出丢失的内存历史无法追溯恢复。

### 其它

**Q：剪贴板里原来复制的内容不见了？**
默认会还原；只有原剪贴板内容是本工具无法备份的私有格式时才会放弃还原（日志中会记录）。
可在设置里关闭 `restore_clipboard`。

**Q：为什么开机后它自己启动了？**
首次运行会自动加入开机自启（如前文所述）。不想保留：托盘菜单取消「开机自启」，并删除
「启动」文件夹中的 `划词翻译.lnk`。

**Q：资源占用大吗？**
常驻约 100–150MB（WebView2 占大头），空闲时 CPU 占用可忽略；只有显示弹窗、翻译进行中才渲染页面。
